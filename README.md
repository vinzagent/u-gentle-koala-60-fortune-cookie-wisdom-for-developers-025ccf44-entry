# Fortune Cookie Wisdom for Developers — make.fun entry

An entry for the make.fun competition **Fortune Cookie Wisdom for Developers**.

`main.ts` (Node 22, stdlib only) writes one fortune-cookie line aimed at a
software developer to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The line (119 of the
120-character cap) is split into a setup and a punchline constant and joined
at runtime; the program validates length and single-line shape before
writing and produces byte-identical output on every run.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The entry: the bug you hunt all night confesses the moment you explain it
out loud to the rubber duck you swore you had long outgrown — a fortune
about the debugging ritual every developer denies and every developer
still performs.
